## What this repository is

A write-up of my own product-management practice, authored by me, for my own portfolio. It discusses
the problem space around enterprise AI security assessment, the methodology I use to design and
validate a scored assessment instrument, and a reference architecture I advocate for
privacy-conscious assessment tools.

Everything in `docs/` was written from scratch for this repository.
